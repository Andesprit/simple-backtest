The accounting model, in full.

Eight rules. Every one of them is a line you can find in the source. Nothing here is inferred, defaulted quietly, or left to the reader.

Simple Backtest accounting rules and their configurable options
Position One long-only, cash-funded instrument FIFO lots
Quantity Fractional units allowed shares is a generic quantity
Execution price Bar open open · close · vwap · custom
Commission 0.1% of notional percentage · flat · tiered · custom
Cash Orders above available cash are rejected raised, never silently clipped
Annualization Inferred from the DatetimeIndex override with periods_per_year
Metrics 20 per run returned as a dict on every result
Errors Raised by default error_policy="continue" collects diagnostics

Install it, pass a DataFrame.

No hosted service, no account, no data vendor. The package runs locally against ordinary pandas data and returns a result object you can read in the REPL.

quick_start.pyPython

from simple_backtest import (
    Backtest,
    BacktestConfig,
    MovingAverageStrategy,
)

strategy = MovingAverageStrategy(
    short_window=10,
    long_window=30,
    shares=10,
)

config = BacktestConfig.default(
    initial_capital=10_000
)

backtest = Backtest(data, config)
results = backtest.run([strategy])

print(results.compare())

Six notebooks.

They run in order, top to bottom. Start at 01 with data loading and a first strategy; by 06 you are running walk-forward optimization.

  1. 01 Basic usage load data, run one strategy, read the result
  2. 02 Candle strategies signals from raw OHLC shape
  3. 03 Technical analysis indicator-driven entries and exits
  4. 04 Machine learning a fitted model as the signal source
  5. 05 Commissions percentage, flat, tiered, and custom costs
  6. 06 Advanced optimization grid, random, and walk-forward search
